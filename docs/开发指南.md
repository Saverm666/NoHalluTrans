工作目录为 `D:\HJFY`。打开根目录 `NoHalluTrans.slnx`；产品源码在 `src/`，参考资料在 `reference/`。核心项目直接嵌入参考目录中的规则 JSON。

## 本机编译与运行

```powershell
Set-Location D:\HJFY
.\scripts\Start-Dev.ps1 -NoLaunch
.\scripts\Start-Dev.ps1 -SkipBuild
```

使用 `scripts/Start-Dev.ps1 -NoLaunch` 只编译，不带参数则编译并启动。开发快捷入口按需生成于 `artifacts/dev/`。更新前先关闭正在运行的开发程序。

所有项目输出集中在 `artifacts/bin/<项目>/`，中间文件集中在 `artifacts/obj/<项目>/`。开发入口 `artifacts/dev/app/` 联接到桌面编译输出，`artifacts/dev/runtime/texlive/` 联接到本机 TeX；本机开发不复制整套环境。临时输出被清理后，重新运行构建即可生成。

本机工具默认位于 `%LOCALAPPDATA%\HjfyBuild`，包含 `dotnet/`、`nuget/` 和 `texlive/`。脚本自动发现 SDK、缓存和 TeX，也可使用 `-Dotnet`、`-TexRoot` 指定。

## 构建便携目录

```powershell
.\scripts\Build.ps1
```

默认执行核心测试、自包含发布及桌面检查，更新两份最新版：`artifacts/NoHalluTrans-Portable/` 不含 TeX，`artifacts/NoHalluTrans-Full/` 含 TeX。构建完整版需要本机已准备好的 TeX；不联网下载、不生成 ZIP。完整版会执行实际翻译和中文编译检查。

可用 `-Edition Portable` 或 `-Edition Full` 单独更新其中一份；`-IncludeTex` 等价于 `-Edition Full`，`-SkipTests` 跳过检查。

先构建临时目录，验证通过后替换对应成品；成功后删除旧程序，不累积 previous 目录。失败时保留原成品。各成品的 data/work/output 会保留。`-OutputDirectory` 指定产物父目录，成品不使用外部目录联接。

## 独立打包

仅需要压缩分发时执行 `scripts/Package.ps1`。该脚本压缩已有便携目录并生成 SHA-256，不重新构建。默认排除 runtime 和 data/work/output 的个人文件；显式加 `-IncludeTex` 才包含环境。默认输出 `artifacts/archives/HJFY-win-x64.zip`，文件已存在时需使用新的 `-Destination`。

## 环境安装验证

`TexRuntimeInstaller` 从 HTTPS TeX Live 镜像下载 install-tl.zip 和 SHA-512 校验文件，校验后使用 portable profile 安装；禁用系统 PATH、文件关联与桌面集成。在 `runtime/.texlive-setup-*` 中独立安装和检查，成功后切换到 `runtime/texlive`，失败或取消保留旧环境。临时目录和子进程 TEMP 均在便携目录中，诊断日志在 data/logs。镜像年度不匹配会停止，不自动跨年升级。

```powershell
& "$env:LOCALAPPDATA\HjfyBuild\dotnet\dotnet.exe" run --project tests/NoHalluTrans.Tests -c Release -- --install-environment D:\HJFY\artifacts\runtime-check\runtime\texlive
```

此验证会真实联网安装，需要新的英文路径。默认核心测试使用受控响应验证校验、取消、失败保留旧环境及成功切换，不联网下载 TeX。

## 便携数据

便携版默认在启动 EXE 同级使用 `data/`（设置、任务记录、缓存、日志）、`work/`（任务文件）和 `output/`（译文）。文件夹内的路径按相对位置保存，整体移动后自动解析到新位置。构建替换现有便携目录时，会保留这三个数据目录；不会自动读取或删除旧版本的 AppData 数据。

## 真实论文批测

核心测试入口支持 `--paper-batch <catalog.json> <保存配置的 data 目录> <TeX 目录> <结果目录> [--auto-packages]`。它读取已保存模型及加密密钥，实际调用接口；不要在目录清单或脚本中写入密钥。目录清单的 `papers` 包含 `id`、`group`、`title`、`source`，需要时可设置 `main_hint`。

每篇论文独立保留源码、日志和翻译缓存，两个论文任务共享模型请求并发上限。已有 `attempt.json` 的论文会跳过；重试前将对应记录移到另一名称，保留工作目录及缓存，避免重复翻译。批测结果应逐篇检查，程序退出成功不等于全部论文成功。

`python3 scripts/summarize-paper-batch.py artifacts/verification/paper-batch` 生成 Markdown、CSV 与 JSON 汇总。此脚本需 `pdfinfo` 和 `pdftotext`；这些工具仅供开发验证，用户使用桌面程序不需要安装。
