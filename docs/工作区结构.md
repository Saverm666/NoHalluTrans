# 工程目录约定

[返回工程首页](../README.md)

| 内容 | 目录 |
| --- | --- |
| 产品代码 | `src/` |
| 测试、固定参考输入 | `tests/` |
| 可运行样例 | `samples/` |
| 开发、验证、构建和打包脚本 | `scripts/` |
| 原生启动器及许可 | `tools/` |
| Python 参考实现、规则与研究归档 | `reference/` |
| 使用、开发和验证说明 | `docs/` |
| 编译输出与中间文件 | `artifacts/bin/`、`artifacts/obj/` |
| 最新轻便版（无 TeX） | `artifacts/NoHalluTrans-Portable/` |
| 最新完整版（含 TeX） | `artifacts/NoHalluTrans-Full/` |
| 按需生成的开发入口 | `artifacts/dev/` |
| 本次验证结果 | `artifacts/verification/` |
| 以后单独打包的文件（需要时才生成） | `artifacts/archives/` |

工程已将原 `windows-app/` 内的代码目录和解决方案提升到顶层，原 `tex-pipeline/` 更名为 `reference/`；相关项目引用和脚本路径同步调整。参考归档内部文件保留原名。

新增程序输出、日志、截图、验证证据均归入 `artifacts/`。便携目录构建与压缩打包独立执行，构建阶段不创建 ZIP。根目录开发启动入口已移除，开发快捷入口按需生成于 `artifacts/dev/`。旧版本、旧验证产物和编译中间文件已清理。

历史验证记录中的版本和结论保持原意；旧版本关于压缩 TeX 环境的说明仅描述当时的交付方式。当前只维护轻便版和完整版各一份最新版；`Build.ps1` 默认更新两份，成功后删除旧程序，保留各自用户数据。轻便版在软件内下载环境，完整版自带 TeX；两份成品均不依赖外部目录联接。
