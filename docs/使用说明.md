# NoHalluTrans

[工程首页](../README.md) · [开发指南](开发指南.md) · [验证记录](VERIFICATION.md)

C# / WinUI 3 桌面软件，将 LaTeX 论文源码翻译为指定语言并重新生成 PDF。提供轻便版（NoHalluTrans-Portable）与完整版（NoHalluTrans-Full）：轻便版只携带程序与所需 .NET/WinUI 运行库，不附带 TeX 编译器、字体和宏包；完整版已附带 TeX，可离线使用。首次使用可在软件内联网安装便携 TeX Live，无需 Python、WSL 或系统级 TeX 安装。

本次提供 Windows 测试版；已完成本机编译和样例链路验证，尚未完成干净系统验收。详细结果见 [验证记录](VERIFICATION.md)。

## 使用发布包

1. 将完整便携目录复制到可写的纯英文路径，例如 `D:\NoHalluTrans-Portable`。保留 `app` 文件夹。`runtime`、`data`、`work`、`output` 在需要时于启动程序同级创建。
2. 双击 `NoHalluTrans.exe`。轻便版在“编译环境”点击“下载环境”，等待基础编译器、中文字体和常用论文宏包安装完成；完整版可直接使用。下载时可取消；失败后可重试。已有环境可检查或修复。也可先配置模型，首次翻译时确认下载环境。
3. 在“模型连接”填写 OpenAI 兼容的接口地址和密钥，点击“获取模型”后从下拉菜单选择，也可手填模型 ID；测试连接并保存。论文正文会发送到此服务；软件没有内置模型或免费翻译额度。
4. 直接输入 arXiv 编号（如 `1706.03762`），也可粘贴 arXiv 链接；本地 TeX 源码压缩包可直接拖入窗口或点击“导入源码包”选择，也支持 `.tex` 与源码文件夹；选择输出目录和 PDF 格式后加入队列。
5. 完成后点击“打开译文”，使用 Windows 默认 PDF 阅读器查看。可导出译后源码和诊断包。

支持 Windows 11 x64；ARM64、旧版 Windows 和其他操作系统不属于本版验收范围。首次安装编译环境、获取 arXiv、调用远程模型和补充宏包需要联网；已有源码、外部译文和已安装宏包可离线使用。

### 文件结构

```text
HJFY/
  NoHalluTrans.exe           双击启动
  使用说明.md
  app/               程序、界面资源、许可与示例
  runtime/texlive/   首次联网安装后生成的便携编译环境
  data/              设置、缓存与日志（使用后生成）
  work/              任务工作文件（使用后生成）
  output/            默认译文 PDF（使用后生成）
```

程序仅保留简体中文、繁体中文和英文界面资源；这不限制论文的翻译语言。默认分发目录没有编译环境。下载后，编译器、宏包、字体和包管理文件全部位于 runtime 内；不会加入系统 PATH 或注册文件关联。删除整个便携目录即可一并移除。

### 外部译文与离线样例

安装编译环境后，`app/samples/bilingual` 可以验证中文编译。在任务“高级选项”选择 `app/samples/translation/translations.zh-Hans.json`，以 `app/samples/translation` 为来源，即可不调用模型运行完整翻译示例。

外部译文格式：

```json
{"fragments":[{"id":"f0000","translation":"译文 ⟦HJFY_0⟧"}]}
```

任务工作目录中的 `request.json` 包含对应片段编号。公式、引用及文件路径的占位符必须原样保留；不要把其它论文的译文文件用于当前工程。

### 任务进度

任务列表和选中任务的详情会显示当前阶段：获取源码 → 原文检查 → 提取与切分 → 翻译正文 → 构建 PDF。

切分时显示已扫描文件数及已切分块数。翻译时显示片段总数、已处理数量，并分别列出新译文、缓存复用和保留原文数量；等待模型回复时显示请求批次和重试轮次。翻译结束后单独进入 PDF 构建阶段，在最终 PDF 写出后才标记完成。

进度条表示当前阶段的进度；无法准确计数的源码准备和编译阶段使用活动指示，不估算整个任务的百分比。

### 术语与错误处理

- “术语表”可添加、修改、删除条目，支持 JSON 数组或 `{"terms":[...]}` 导入。
- 多个主文件时，任务显示“请选择主文件”；从候选列表选择后重新运行。
- 翻译多轮校验仍失败的片段保留原文，任务标记“完成，需检查”，详情显示片段编号。
- 编译错误会触发诊断修复；仍失败时保留译后源码和日志。首次原文编译失败也会记录原因。
- 取消终止编译进程树；重新运行创建新副本并复用有效缓存。重新打开软件后，中断任务需要手动重新运行。
- 源码会复制到独立目录，原工程不被修改；中文来源和输出路径支持。工程内部非 ASCII 文件名可能受 TeX 工具限制，任务会提示具体文件。
- shell escape 默认关闭。可信工程确需调用外部程序时，可以在任务高级选项显式启用。

### 数据与补包

默认数据均保存在便携目录内，与启动程序 `NoHalluTrans.exe` 同级：

- `data/`：设置、术语、加密密钥、任务记录、翻译缓存和诊断日志。
- `work/`：任务工作目录、源码副本和编译文件。
- `output/`：默认最终 PDF 目录；也可在主页更改。仅保存所选格式的最终 PDF，源码、日志及编译中间文件保存在 `work/`。

PDF 格式支持“仅目标语言”“双语交替”和“双栏并排（左原文、右译文）”。双语格式按页码配对，页数不一致时缺失位置留白；原文编译失败则无法生成双语格式。文件自动命名，同名时添加序号。

整体移动软件目录时，默认工作目录和目录内的历史任务路径会随之调整。关闭程序后删除整个便携目录，即可清理这些软件数据；手动指定到外部目录的文件需单独管理。旧版 AppData 数据不会自动导入或删除。密钥仍由 Windows DPAPI 加密，仅原 Windows 用户可解密；换用户或电脑后需要重新填写密钥。

“下载环境”安装完整的基础编译器、中文支持和常用论文依赖，与“自动补充缺失宏包”是两个独立功能。初次安装期间需要联网，所需时间取决于网络速度；下载安装工具时显示已下载大小，安装宏包时显示包数量进度。取消会终止安装进程，未完成目录不会启用。修复会重新下载并校验基础环境，检查通过后才替换原环境，额外补装的宏包可能需要重新下载。安装日志保存在 `data/logs/tex-setup-*.log`。

额外宏包默认自动下载，可在“编译环境”关闭并保存。软件仅安装与内置 TeX Live 同年度的包，不自动跨年升级。软件目录需要可写；网络不可用或仓库年度不匹配时会明确失败。基础宏包及版本见 `runtime/texlive/hjfy-packages.txt` 和 `hjfy-runtime.json`。请整体保留 `runtime/texlive/`，不要单独移动或删减其中的宏包与字体。
